# เปิดให้เพื่อนใช้ Agent Office

เพื่อนจะใช้ทีม AI บน **เครื่องของคุณ** ผ่านเว็บ โดยไม่ต้องติดตั้งอะไร เครื่องคุณต้องเปิดแอปค้างไว้ตลอดเวลาที่เพื่อนใช้

## 1. เปิดแอปบนเครื่องคุณ

- Mac: ดับเบิลคลิก `start.command`
- Windows: ดับเบิลคลิก `start.bat`

## 2. ตั้งค่า Claude ที่เพื่อนจะใช้

เพื่อนใช้ key ของเซิร์ฟเวอร์ ไม่ใช่การล็อกอิน Claude ส่วนตัวของคุณ (บัญชีส่วนบุคคลแชร์ให้คนอื่นใช้ไม่ได้)

- **SWU AI**: ใส่ `SWU_API_KEY=...` ในไฟล์ `.env` แล้วเปิดแอปใหม่ (ระบบใช้ตัวนี้ก่อน)
- หรือ **Anthropic API key**: ใส่ในปุ่ม "แชร์ให้เพื่อน" ข้อ 1
- **เพื่อนใส่ key ของตัวเองได้ด้วย** (ไอคอนเฟือง > "API key ของคุณเอง") ทีมจะใช้โทเค็นของคุณก่อน เมื่อหมดหรือโควตาที่ให้เพื่อนหมด จะสลับไปใช้ key ของเพื่อนแล้วทำงานต่อทันทีในโปรเจกต์เดิม ไม่ต้องเริ่มใหม่ (ดูข้อ 5)

## 3. ทำให้เพื่อนเปิดเครื่องคุณได้

**เพื่อนอยู่ Wi-Fi เดียวกัน** ไม่ต้องทำอะไรเพิ่ม ลิงก์จะเป็น `http://192.168.x.x:3000` อัตโนมัติ
ครั้งแรกถ้ามีหน้าต่าง firewall ถามเรื่อง Node.js ให้กดอนุญาต (Windows เลือก Private networks)

**เพื่อนอยู่นอกบ้าน** ติดตั้ง `cloudflared` ครั้งเดียว (ฟรี ไม่ต้องสมัครบัญชี):

```bash
winget install --id Cloudflare.cloudflared
```

Mac ใช้ `brew install cloudflared` แล้วเปิด Agent Office ใหม่ จากนั้น:

1. กดปุ่ม **แชร์ให้เพื่อน** แล้วกด **เปิดให้คนนอกบ้านเข้า** (รอไม่เกิน 30 วินาที)
2. ได้ลิงก์ `https://xxxx.trycloudflare.com` ลิงก์เชิญทุกอันจะใช้ที่อยู่นี้ให้เอง แล้วส่งลิงก์เชิญให้เพื่อน
3. แอปที่ทีมสร้าง (เช่นร้านค้าที่มีสมัครสมาชิก/login) ได้ลิงก์ https **แยกของตัวเอง** อัตโนมัติเมื่อเพื่อนเปิดดู จึงสมัครและ login ในแอปได้จริงเหมือนอยู่ในบ้าน
4. อยากส่งแอปให้คนที่ไม่ได้ใช้ Agent Office ลอง: เปิดโปรเจกต์ > แท็บ Preview > **แชร์แอปนี้ออกนอกบ้าน** แล้วคัดลอกลิงก์

ที่อยู่ `trycloudflare.com` จะเปลี่ยนทุกครั้งที่ปิดแล้วเปิดใหม่ (รหัสเชิญเดิมยังใช้ได้ แค่ส่งลิงก์ที่อยู่ใหม่ให้เพื่อน)
อยากให้เปิดเองทุกครั้งที่เริ่มแอป ใส่ `PUBLIC_TUNNEL=1` ใน `.env` อยากได้ที่อยู่ถาวร ใช้ named tunnel ของ Cloudflare หรือโดเมนของคุณเอง แล้วใส่ `PUBLIC_URL=https://...` ใน `.env`
`npm run doctor` บอกได้ว่าเครื่องนี้มี cloudflared แล้วหรือยัง

## 4. ชวนเพื่อนเข้าโปรเจกต์

1. เปิดโปรเจกต์ในแถบซ้าย แล้วกด **ชวนเพื่อนร่วมแก้**
2. พิมพ์ชื่อเพื่อน ใส่หลายคนได้โดยคั่นด้วยจุลภาค เช่น `ต้น, ปอย, มิ้นท์`
3. ตั้งโควตาโทเค็นต่อคน แล้วกด **สร้างลิงก์เชิญ** (ระบบคัดลอกลิงก์ทั้งหมดไว้ให้)
4. ส่งลิงก์ของแต่ละคนทาง LINE หรือแชทอื่น

ชวนแบบยังไม่ผูกกับโปรเจกต์ใด ให้ใช้ปุ่ม **แชร์ให้เพื่อน** ข้อ 3 แทน เพื่อนจะเริ่มโปรเจกต์ของตัวเองได้

## 5. เพื่อนทำอะไรได้บ้าง

- เปิดลิงก์แล้วเข้าโปรเจกต์ได้ทันที เห็นทีม AI ทำงานแบบสด ไฟล์ ผลเทสต์ และ Preview
- สั่งงานเพิ่มต่อจากที่ทำค้างไว้ได้ ("สั่งงานเพิ่มในโปรเจกต์นี้")
- ชวนคนอื่นต่อได้หลายคน โควตาของคนที่ถูกชวนจะแบ่งจากโควตาของคนชวน
- เริ่มโปรเจกต์ใหม่ของตัวเองได้
- ลบได้เฉพาะโปรเจกต์ที่ตัวเองสร้าง และเห็นแค่โปรเจกต์ของตัวเองกับโปรเจกต์ที่ถูกชวน
- **ใช้ key ของตัวเองต่อเมื่อโทเค็นของคุณหมด**: เพื่อนเปิดไอคอนเฟือง เลือกชนิด key (SWU AI หรือ Anthropic) วาง key แล้วบันทึก
  - ใส่ไว้ก่อน: เมื่อโทเค็นของคุณหมดกลางงาน ทีมสลับไปใช้ key ของเพื่อนแล้วทำต่อเองทันที (ในแชทจะบอกว่าสลับแล้ว)
  - ใส่ทีหลัง: งานหยุดพร้อมข้อความว่าโทเค็นหมด เพื่อนใส่ key แล้วกด **ทำงานต่อ** ทีมทำต่อจากจุดเดิม
  - โทเค็นที่ใช้ผ่าน key ของเพื่อนไม่ถูกนับในตัวนับของคุณ และไม่หักจากโควตาที่ให้เพื่อน
  - key ของเพื่อนเก็บในเบราว์เซอร์ของเพื่อน ส่งมาที่เครื่องคุณเฉพาะตอนสั่งงาน ไม่ถูกบันทึกลงเครื่องคุณ
  - ทุกคนในโปรเจกต์ทำงานต่อจากกันได้ เช่น A เริ่มด้วยโทเค็นของคุณ พอหมด B กด ทำงานต่อ ด้วย key ของ B

## 6. ยกเลิกสิทธิ์

- เอาเพื่อนออกจากโปรเจกต์: ปุ่ม **ชวนเพื่อนร่วมแก้** แล้วเอาเครื่องหมายถูกออก
- ยกเลิกลิงก์ถาวร: ปุ่ม **แชร์ให้เพื่อน** แล้วกด **ยกเลิก** ข้างชื่อเพื่อน

## ข้อควรรู้

- งานของเพื่อนใช้โทเค็นจาก key ของคุณก่อน (จนกว่าเพื่อนจะสลับไปใช้ key ของตัวเอง) ตั้งโควตาให้เหมาะ และดูยอดใช้ได้ในหน้าแชร์
- ลิงก์ออกนอกบ้านเปิดให้ทุกคนที่มีลิงก์เข้าถึงหน้าเว็บได้ แต่ Agent Office ยังต้องใช้ลิงก์เชิญหรือรหัสเจ้าของเหมือนเดิม ไม่ใช้แล้วกด **ปิดลิงก์คนนอกบ้าน** ได้
- โค้ดที่ AI เขียนถูกรันบนเครื่องคุณใน sandbox ที่จำกัดสิทธิ์ (อ่านได้แค่โฟลเดอร์ชั่วคราว เขียนไฟล์/เปิดโปรแกรมอื่นไม่ได้)
- ปิดหน้าต่างแอปหรือปิดเครื่อง = เพื่อนใช้ไม่ได้ชั่วคราว ลิงก์เดิมกลับมาใช้ได้เมื่อเปิดใหม่ (ถ้าใช้ tunnel ต้องส่งลิงก์ tunnel ใหม่)
