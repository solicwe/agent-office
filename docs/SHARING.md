# เปิดให้เพื่อนใช้ Agent Office

เพื่อนจะใช้ทีม AI บน **เครื่องของคุณ** ผ่านเว็บ โดยไม่ต้องติดตั้งอะไร เครื่องคุณต้องเปิดแอปค้างไว้ตลอดเวลาที่เพื่อนใช้

## 1. เปิดแอปบนเครื่องคุณ

- Mac: ดับเบิลคลิก `start.command`
- Windows: ดับเบิลคลิก `start.bat`

## 2. ตั้งค่า Claude ที่เพื่อนจะใช้

เพื่อนใช้ key ของเซิร์ฟเวอร์ ไม่ใช่การล็อกอิน Claude ส่วนตัวของคุณ (บัญชีส่วนบุคคลแชร์ให้คนอื่นใช้ไม่ได้)

- **SWU AI**: ใส่ `SWU_API_KEY=...` ในไฟล์ `.env` แล้วเปิดแอปใหม่ (ระบบใช้ตัวนี้ก่อน)
- หรือ **Anthropic API key**: ใส่ในปุ่ม "แชร์ให้เพื่อน" ข้อ 1

## 3. ทำให้เพื่อนเปิดเครื่องคุณได้

**เพื่อนอยู่ Wi-Fi เดียวกัน** ไม่ต้องทำอะไรเพิ่ม ลิงก์จะเป็น `http://192.168.x.x:3000` อัตโนมัติ
ครั้งแรกถ้ามีหน้าต่าง firewall ถามเรื่อง Node.js ให้กดอนุญาต (Windows เลือก Private networks)

**เพื่อนอยู่นอกบ้าน** เปิด terminal อีกหน้าต่างแล้วรัน:

```bash
npx cloudflared tunnel --url http://localhost:3000
```

จะได้ลิงก์ `https://xxxx.trycloudflare.com` ให้คัดลอกไปใส่ในปุ่ม "แชร์ให้เพื่อน" ข้อ 2 (ที่อยู่ที่เพื่อนเปิดได้)
ลิงก์นี้เปลี่ยนทุกครั้งที่รัน tunnel ใหม่ ถ้ารันใหม่ต้องอัปเดตช่องนี้และส่งลิงก์ใหม่ให้เพื่อน

## 4. ชวนเพื่อนเข้าโปรเจกต์

1. เปิดโปรเจกต์ในแถบซ้าย แล้วกด **ชวนเพื่อนร่วมแก้**
2. พิมพ์ชื่อเพื่อน ใส่หลายคนได้โดยคั่นด้วยจุลภาค เช่น `ต้น, ปอย, มิ้นท์`
3. ตั้งโควตาโทเค็นต่อคน แล้วกด **สร้างลิงก์เชิญ** (ระบบคัดลอกลิงก์ทั้งหมดไว้ให้)
4. ส่งลิงก์ของแต่ละคนทาง LINE หรือแชทอื่น

ชวนแบบยังไม่ผูกกับโปรเจกต์ใด ให้ใช้ปุ่ม **แชร์ให้เพื่อน** ข้อ 3 แทน เพื่อนจะเริ่มโปรเจกต์ของตัวเองได้

## 5. เพื่อนทำอะไรได้บ้าง

- เปิดลิงก์แล้วเข้าโปรเจกต์ได้ทันที เห็นทีม AI ทำงานแบบสด ไฟล์ ผลเทสต์ และ Preview
- สั่งงานเพิ่มต่อจากที่ทำค้างไว้ได้ ("สั่งงานเพิ่มในโปรเจกต์นี้")
- ชวนคนอื่นต่อได้หลายคน โควตาของคนที่ถูกชวนจะแบ่งจากโควตาของคนชวน
- เริ่มโปรเจกต์ใหม่ของตัวเองได้
- ลบได้เฉพาะโปรเจกต์ที่ตัวเองสร้าง และเห็นแค่โปรเจกต์ของตัวเองกับโปรเจกต์ที่ถูกชวน

## 6. ยกเลิกสิทธิ์

- เอาเพื่อนออกจากโปรเจกต์: ปุ่ม **ชวนเพื่อนร่วมแก้** แล้วเอาเครื่องหมายถูกออก
- ยกเลิกลิงก์ถาวร: ปุ่ม **แชร์ให้เพื่อน** แล้วกด **ยกเลิก** ข้างชื่อเพื่อน

## ข้อควรรู้

- ทุกงานของเพื่อนใช้โทเค็นจาก key ของคุณ ตั้งโควตาให้เหมาะ และดูยอดใช้ได้ในหน้าแชร์
- โค้ดที่ AI เขียนถูกรันบนเครื่องคุณใน sandbox ที่จำกัดสิทธิ์ (อ่านได้แค่โฟลเดอร์ชั่วคราว เขียนไฟล์/เปิดโปรแกรมอื่นไม่ได้)
- ปิดหน้าต่างแอปหรือปิดเครื่อง = เพื่อนใช้ไม่ได้ชั่วคราว ลิงก์เดิมกลับมาใช้ได้เมื่อเปิดใหม่ (ถ้าใช้ tunnel ต้องส่งลิงก์ tunnel ใหม่)
