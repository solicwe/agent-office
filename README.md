# Agent Office

ทีม AI 7 ตำแหน่งที่รับงานเขียน/แก้โปรแกรม แล้ววิเคราะห์ ออกแบบ เขียนโค้ด ทดสอบ แก้บั๊ก และรีวิว วนจนกว่างานจะผ่าน
แสดงผลเป็นออฟฟิศการ์ตูนที่ตัวละครเดินไปคุยกันและส่งงานกัน

## เริ่มใช้งาน (ง่ายที่สุด)

ต้องมี [Node.js](https://nodejs.org/) เวอร์ชัน 22.13 ขึ้นไป แล้วดาวน์โหลดโปรเจกต์นี้ (ปุ่ม Code > Download ZIP บน GitHub หรือ `git clone`)

| เครื่อง | วิธีเปิด |
|---|---|
| **Mac** | ดับเบิลคลิก `start.command` (ครั้งแรกถ้า macOS เตือน ให้คลิกขวา > Open) |
| **Windows** | ดับเบิลคลิก `start.bat` |
| **Linux** | รัน `./start.sh` |

ครั้งแรกจะติดตั้งให้เอง แล้วเปิดเว็บ http://localhost:3000 ให้อัตโนมัติ จากนั้นสั่งงานทุกอย่างผ่านหน้าเว็บได้เลย
ใส่ key ได้ในหน้าตั้งค่าบนเว็บ หรือในไฟล์ `.env` (สร้างให้จาก `.env.example` ตอนเปิดครั้งแรก)

แบบใช้คำสั่งเอง:

```bash
npm install
npm run doctor
npm start
```

`npm run doctor` ตรวจว่าเครื่องพร้อมหรือยัง (เวอร์ชัน Node, sandbox, สิทธิ์เขียนโฟลเดอร์, พอร์ต, key ที่ใช้ได้) โดยไม่เสียโทเค็น ถ้าเครื่องไม่พร้อม `npm start` จะหยุดเองพร้อมบอกสาเหตุ

### เชื่อม Claude (เลือกในหน้าตั้งค่า ไอคอนเฟือง)

- **SWU AI (มศว)** ช่องทางหลักเมื่อมี `SWU_API_KEY` ใน `.env` เรียกผ่าน gateway `https://swuai.swu.ac.th/swu/api/service` ตามคู่มือ API Services (ปุ่ม "ดึงรายชื่อ" แสดงโมเดลที่ key ใช้ได้)
- **Claude ในเครื่องนี้** ใช้ token จากบัญชีที่ล็อกอิน Claude Code ไว้ เหมาะสำหรับทดสอบ ถ้ายังไม่ได้ล็อกอินหรือหมดอายุ ให้รัน `claude` ใน terminal แล้วพิมพ์ `/login`
- **Anthropic API key** ใส่ในหน้าตั้งค่า

```
# .env
SWU_API_KEY=swu_ai_...
SWU_MODEL=anthropic/claude-sonnet-5.5
```

### ตัวนับโทเค็น

หัวเว็บแสดง "ใช้ไปแล้ว X tokens" นับจากจำนวนจริงที่ AI ส่งกลับมาทุกครั้ง ถ้าต้นทางตอบว่าเครดิตหมด จะขึ้นว่า "โทเค็นหมด" และงานหยุดแบบทำต่อได้
ถ้าหมดนานเกิน 30 นาทีแล้วกลับมาใช้ได้ ถือว่าต้นทางรีเซ็ตโควตาแล้ว ตัวนับจะเริ่มจาก 0 ใหม่ (SWU AI ไม่มีช่องทางบอกยอดคงเหลือ)

## แอปที่ทีมสร้าง

- **แอปจริง (ค่าเริ่มต้นสำหรับเว็บและระบบ):** มีเซิร์ฟเวอร์ Node, ฐานข้อมูล (ไฟล์ JSON ใน `data/`), ระบบสมัครสมาชิกและ login จริง (รหัสผ่านเข้ารหัสด้วย scrypt, session cookie) โดยใช้ชุดเริ่มต้นใน `src/starter-kit/` ไม่ต้องลงแพ็กเกจเพิ่ม บัญชีแรกที่สมัครจะเป็นแอดมิน
- **เว็บ static:** สำหรับงานเล็กที่ไม่มีบัญชีผู้ใช้ เช่น เครื่องคิดเลขหรือเกม
- แต่ละโปรเจกต์รันเป็นเว็บของตัวเองบนพอร์ต 4100 ขึ้นไป ข้อมูลและการ login ไม่หายเมื่อเปลี่ยนหน้า
- QA Lab เปิดเซิร์ฟเวอร์จริง ไล่เปิดทุกหน้าที่ลิงก์ถึงกัน (ลิงก์เสียถือว่าไม่ผ่าน) และรันเทสต์ API กับเซิร์ฟเวอร์ที่รันอยู่
- โค้ดของแอปรันใน sandbox: อ่านได้เฉพาะโฟลเดอร์โปรเจกต์ เขียนได้เฉพาะ `data/` เปิดโปรแกรมอื่นและใช้ `node:sqlite` ไม่ได้ ข้อจำกัด: แอปยังเชื่อมต่ออินเทอร์เน็ตได้

## รหัสเจ้าของ

เจ้าของเครื่องยืนยันตัวตนด้วยรหัสในไฟล์ `data/owner-token.txt` (แอปที่ทีมสร้างอ่านไฟล์นี้ไม่ได้) `start.bat` / `start.command` เปิดเว็บพร้อมรหัสให้อัตโนมัติ ถ้าเปิดเองแล้วเจอหน้าล็อก ให้ใส่รหัสจากไฟล์นั้น

## ฟีเจอร์

- **ช่วยคิดโจทย์**: ปุ่ม "ไม่รู้จะสั่งอะไร? ให้ช่วยถาม" Nina ถามทีละข้อพร้อมตัวเลือก แล้วสรุปเป็นโจทย์ให้
- **รายโปรเจกต์**: แถบซ้ายแสดงทุกโปรเจกต์ แต่ละโปรเจกต์เก็บประวัติทุกรอบงาน และสั่งงานเพิ่ม (แก้ไข/เพิ่มฟีเจอร์) ต่อจากไฟล์ล่าสุดได้
- **บันทึกลงโฟลเดอร์**: ทุกไฟล์ถูกเขียนลง `projects/<ชื่อโปรเจกต์>/` ทันที มีปุ่มบันทึกลงโฟลเดอร์ที่เลือกเองและดาวน์โหลด .zip
- **ลิงก์เดโม่**: `/p/<ชื่อโปรเจกต์>/` เปิดเว็บที่ทีมสร้างได้ทันที แชร์ให้ใครดูก็ได้
- **ชวนเพื่อนร่วมแก้โปรเจกต์**: ปุ่ม "ชวนเพื่อนร่วมแก้" ในโปรเจกต์ ชวนหลายคนพร้อมกันได้ เพื่อนเปิดลิงก์แล้วเข้าโปรเจกต์นั้นทันที ดูทีมทำงานแบบสด ดูไฟล์ สั่งงานเพิ่มต่อจากที่ทำค้างไว้ และชวนคนอื่นต่อได้ (แบ่งโควตาจากของตัวเอง) ดูขั้นตอนเต็มที่ [docs/SHARING.md](docs/SHARING.md)
- **ลบโปรเจกต์**: ปุ่ม "ลบ" ในโปรเจกต์ (เฉพาะเจ้าของโปรเจกต์ ลบไม่ได้ระหว่างทีมกำลังทำงาน)
- **แชร์ให้เพื่อนใช้**: ปุ่ม "แชร์ให้เพื่อน" สร้างลิงก์เชิญพร้อมโควตาโทเค็น เพื่อนเห็นเฉพาะโปรเจกต์ของตัวเอง ยกเลิกลิงก์ได้ เพื่อนใช้ API key ของเจ้าของ (ตั้งในหน้าแชร์) เพราะบัญชี Claude ส่วนบุคคลแชร์ให้คนอื่นใช้ไม่ได้
- **งบโทเค็น**: หัวเว็บแสดง "เหลือ X tokens" ตั้งงบและรีเซ็ตได้ในหน้าตั้งค่า งบหมดทีมหยุดเอง

เพื่อนในวง Wi-Fi เดียวกันเปิดลิงก์ได้เลย ถ้าอยู่นอกบ้าน ใช้ tunnel แล้วนำลิงก์ https ที่ได้ไปใส่ในหน้าแชร์:

```bash
npx cloudflared tunnel --url http://localhost:3000
```

## ย้ายไปเครื่องอื่น / เปิดตลอดเวลา

โค้ดอยู่บน GitHub ครบ ส่วนที่อยู่แค่ในเครื่อง (ไม่ขึ้น git) ต้องคัดลอกเองถ้าอยากเก็บไว้:

| ไฟล์ / โฟลเดอร์ | คืออะไร |
|---|---|
| `.env` | SWU / Anthropic key |
| `projects/` | โปรเจกต์ทั้งหมดที่ทีมสร้าง รวมฐานข้อมูลของแต่ละแอป |
| `data/` | รหัสเจ้าของ, ลิงก์เชิญเพื่อน, ตัวนับโทเค็น |

**Docker** (เครื่องไหนก็ได้ที่มี Docker เปิดตลอด และเปิดใหม่เองหลังรีบูต):

```bash
docker build -t agent-office .
docker run -d --name agent-office --restart unless-stopped -p 3000:3000 -p 4100-4119:4100-4119 -v agent-office-data:/app/data -v agent-office-projects:/app/projects -e SWU_API_KEY=swu_ai_... agent-office
docker logs agent-office
```

ลิงก์เข้าสู่ระบบเจ้าของจะอยู่ใน `docker logs` (Claude Code ในเครื่องใช้ใน Docker ไม่ได้ ให้ใช้ SWU หรือ API key)

**เปิดเองตอนเปิดเครื่อง:** Windows ใส่ shortcut ของ `start.bat` ในโฟลเดอร์ `shell:startup` ส่วน Mac เพิ่ม `start.command` ใน System Settings > General > Login Items

ปิดหน้าต่างแอปหรือเครื่องดับระหว่างทำงานได้ งานจะถูกบันทึกไว้ และกด "ทำงานต่อจากที่ค้าง" ได้เมื่อเปิดใหม่

## ความปลอดภัย

- เจ้าของต้องมีรหัสเจ้าของ (`data/owner-token.txt`) คนอื่นต้องมีลิงก์เชิญ ไม่งั้นเรียก API ไม่ได้ และหน้าเว็บอื่น (รวมถึงแอปที่ทีมสร้าง) สั่งงาน Agent Office แทนคุณไม่ได้
- โค้ดที่ AI เขียน ทั้งตอนทดสอบและตอนเปิดเดโม่ รันใน process แยกภายใต้ Node permission model: อ่านได้เฉพาะโฟลเดอร์ของตัวเอง เขียนได้เฉพาะ `data/` เปิดโปรแกรมอื่น เปิด worker และใช้ `node:sqlite` ไม่ได้
- แต่ละแอปเป็นคนละ origin กับ Agent Office (พอร์ตต่างกัน)
- ข้อจำกัด: แอปที่ AI สร้างยังเชื่อมต่ออินเทอร์เน็ตได้ ถ้าจะเปิดให้คนนอกใช้บนเซิร์ฟเวอร์จริง ควรรันใน Docker หรือเครื่องแยก

## ข้อจำกัด

- ไม่มีขั้นตอน build และไม่ใช้แพ็กเกจ npm ในแอปที่สร้าง (ใช้ชุดเริ่มต้นแทน) ฐานข้อมูลเป็นไฟล์ JSON เหมาะกับข้อมูลระดับร้านเล็กถึงกลาง
- QA ทดสอบ API กับเซิร์ฟเวอร์จริงและเปิดทุกหน้า แต่ยังไม่ได้กดปุ่มในหน้าเว็บแบบเบราว์เซอร์จริง (ส่วนนี้ตรวจด้วย code review)
- เพื่อนที่เข้าผ่าน tunnel เห็นหน้าเว็บของแอปได้ แต่ใช้ login ไม่ได้ เพราะ tunnel เปิดแค่พอร์ต 3000 (ในวง Wi-Fi เดียวกันใช้ได้เต็มที่)
- คุณภาพของงานขึ้นกับโมเดลและเครดิตที่มี งานใหญ่ใช้หลายแสนถึงล้านโทเค็น
